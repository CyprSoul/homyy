# «Привіт, Siri, Хомі» на iPhone

Siri записує питання, надсилає його Хомі на твій ПК (через Tailscale, як і чат на телефоні)
і читає відповідь уголос. Працює вдома й поза домом, коли ПК увімкнений.

## Що потрібно
- На iPhone увімкнений **Tailscale** (як для чату).
- **Ключ API** Open WebUI (той самий, що в `agent\config.toml`, розділ `[openwebui]`).
- **ID моделі** Хомі в Open WebUI — `homyy` (Робочий простір → Моделі → Хомі, сірий напис під назвою).

## Створення швидкої команди (≈5 хв)
Застосунок **«Швидкі команди»** (Shortcuts) → **+** → назва **«Хомі»**. Дії по черзі:

1. **«Диктувати текст»** (Dictate Text) → мова: Українська, зупинка: «Після паузи».
2. **«Отримати вміст URL»** (Get Contents of URL):
   - URL: `https://cyprsoul.tail1c24ee.ts.net/api/chat/completions`
   - Метод: **POST**
   - Заголовки:
     - `Authorization` → `Bearer sk-ТВІЙ-КЛЮЧ`
     - `Content-Type` → `application/json`
   - Тіло запиту: **JSON**
     - `model` (текст) → `homyy`
     - `stream` (логічне) → **false**
     - `messages` (масив) → один елемент **Словник**:
       - `role` (текст) → `user`
       - `content` (текст) → змінна **«Продиктований текст»**
3. **«Отримати значення словника»** → ключ `choices` → **«Отримати елемент зі списку»** → перший.
4. **«Отримати значення словника»** → ключ `message` → ще раз **«Отримати значення словника»** → ключ `content`.
5. **«Промовити текст»** (Speak Text) → результат попереднього кроку, мова Українська.

## Користування
- «**Привіт, Siri, Хомі**» → Siri каже «слухаю» → говориш питання → Хомі відповідає голосом iPhone.
- Можна додати на головний екран або на кнопку дії (iPhone 15 Pro і новіші).

## Якщо не працює
- **Помилка з'єднання** → увімкни Tailscale на iPhone і перевір, що ПК не спить.
- **401 / Unauthorized** → перевір ключ API (без пробілів, з «Bearer » на початку).
- **Відповідь порожня** → перевір ID моделі (`homyy`).
