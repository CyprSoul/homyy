# Ручні тести голосової Хомі

Проганяти на ПК після оновлень. Позначай ✅ / ❌ і кидай рядки з `agent\homyy.log`.

## Музика (інструмент `media`)
Увімкнути YouTube Music або Apple Music, потім після «Хооміі»:
- [ ] «Постав на паузу»
- [ ] «Продовжуй»
- [ ] «Наступна пісня» / «Попередня пісня»
- [ ] «Зроби гучніше» / «Тихіше» / «Вимкни звук»

## Програми й сайти (`open_app`, `open_website`)
- [ ] «Відкрий Steam»
- [ ] «Відкрий YouTube»
- [ ] «Відкрий калькулятор»
- [ ] «Відкрий сайт rozetka.com.ua»
- [ ] Скласти список програм, які відкриваю найчастіше (Telegram, Discord, браузер, танки…) → додати в `[apps]` у `config.toml`

## Екран (`look_at_screen`)
- [ ] «Що в мене на екрані?»
- [ ] Відкрити помилку чи англійський текст → «Що тут написано?» / «Переклади, що на екрані»

## Ігровий режим
- [ ] Запустити танки → у журналі «🎮 Гра! Звільняю відеокарту…», з'являється HUD-приціл
- [ ] У грі «Хооміі» → «Котра година?» → відповідає (перший раз до ~20 с)
- [ ] Закрити гру → «🎮 Гру закрито…», знову сфера
- [ ] «Це гра» / «Це не гра» на віконній програмі

## Пам'ять
- [ ] «Запам'ятай, що я люблю зелений чай» → з'явилось у Персоналізація → Пам'ять
- [ ] У чаті Open WebUI: «Що я люблю пити?» → чай

## Швидкість
- [ ] «Котра година?»: [розпізнала за] < 1 с, [думала] < 4 с

## Керування Windows
- [ ] «Вимкни комп'ютер через годину» → перепитує → «так» → у треї Windows повідомлення про вимкнення; «Скасуй вимкнення»
- [ ] «Вимкни комп'ютер через годину» → «ні» → нічого не відбувається
- [ ] «Заблокуй комп'ютер»
- [ ] «Нагадай через 2 хвилини випити води» → через 2 хв Хомі каже вголос
- [ ] «Зроби скриншот» → файл у Зображення\Хомі
- [ ] «Знайди файл …» (частина назви файлу, який точно є)
- [ ] «Наведи порядок у Завантаженнях» → перепитує зі списком (Картинки: N, …) → «так»
- [ ] «Закрий Discord» → перепитує → «так»
- [ ] «Переведи комп'ютер у сон» → перепитує → «так»

## Браузер і нотатки
- [ ] «Знайди на Розетці навушники» → відкривається пошук Rozetka
- [ ] «Знайди на YouTube рецепт борщу»
- [ ] Вказати шлях до Obsidian у `config.toml` → `[obsidian] vault = "…"`
- [ ] «Що в моїх нотатках про тренування?»
- [ ] «Запиши в нотатки: купити протеїн» → рядок у «Хомі.md»

## Telegram-бот
Налаштування (один раз):
1. У Telegram знайти **@BotFather** → `/newbot` → ім'я «Хомі» → логін, що закінчується на `bot` → скопіювати **токен**.
2. `notepad agent\config.toml` → додати:
   ```
   [telegram]
   token = "токен-від-BotFather"
   ```
3. Перезапустити Хомі → написати своєму боту будь-що → бот відповість «додай свій ID …».
4. Додати ID: `allowed_ids = [123456789]` у той самий розділ → перезапустити Хомі.

Тести:
- [ ] Текстом: «Котра година?»
- [ ] Голосовим: «Яка погода в Києві?» (бот покаже, що почув, і відповість)
- [ ] Під час гри: повідомлення чекає й обробляється після гри
- [ ] Хтось інший пише боту → відмова

## Monobank і Gmail (лише читання)
- [ ] Monobank: https://api.monobank.ua/ → увійти через застосунок → скопіювати токен → `config.toml`: `[monobank] token = "…"`
- [ ] «Скільки я витратив за тиждень?» / «Який у мене баланс?»
- [ ] Gmail: Google-акаунт → Безпека → двоетапна перевірка увімкнена → «Паролі застосунків» → створити → `config.toml`: `[gmail] address = "…"`, `app_password = "…"`
- [ ] «Що нового в пошті?»

## Siri
- [ ] Налаштувати за [`docs/siri.md`](siri.md) → «Привіт, Siri, Хомі» → питання → відповідь

## Без терміналу й розмова на кілька тем
- [ ] `scripts\install-autostart.ps1` → закрити старе вікно Хомі → запустити ярлик «Хомі» з Робочого столу → вікна терміналу немає, лише сфера
- [ ] Правий клік по сфері → «Відкрити журнал»
- [ ] Розмова: питання → після сигналу продовжити без «Хомі» (12 с) → «Нова тема» → інше питання
