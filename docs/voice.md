# Новий голос Хомі (етап 9)

## Варіант 1 — локальний StyleTTS2 (рекомендований)
Український StyleTTS2 від спільноти: кілька природних голосів, **автоматичні наголоси**,
цифри й скорочення сам перетворює на слова. Працює **на твоєму ПК** (процесор), без інтернету
й без Microsoft. Підключається так само, як Поліна (OpenAI-сумісний API).

### 1. Запуск (один раз; перше завантаження — кілька ГБ і 5–15 хв)
```
cd C:\homyy\repo\config\tts-uk
docker compose up -d
```
Готовність: `docker logs -f tts_uk_api` → рядок про запуск Uvicorn; або відкрий http://localhost:8003/v1/audio/voices — має бути список голосів.

### 2. Прослухати голоси
```
cd C:\homyy\repo
.venv\Scripts\python -m agent.voice_audition
```
Відкриється папка `C:\homyy\voices` — у кожному файлі той самий текст іншим голосом. Обери найкращий.

### 3. Підключити до голосової Хомі
`notepad agent\config.toml`:
```
[tts]
url = "http://localhost:8003/v1/audio/speech"
model = "multi"
voice = "Назва обраного голосу"
speed = 1.0
```
Перезапусти Хомі.

### 4. Підключити до чату Open WebUI
Адмін → Аудіо → Синтез мови:
- URL-адреса API: `http://host.docker.internal:8003/v1`
- Модель TTS: `multi`
- Голос TTS: назва обраного голосу

### Якщо наголос неправильний
Постав знак `` ` `` перед наголошеним складом прямо в тексті (для власних назв), наприклад ``Т`имофій``.

## Варіант 2 — ElevenLabs (хмара, платно)
Найприродніший голос (емоції, інтонації), але текст іде на їхні сервери й після безкоштовного ліміту — оплата.
Можна порівняти на elevenlabs.io (модель Multilingual), якщо локальний варіант не сподобається.

## Повернутися до Поліни
У `config.toml` прибери розділ `[tts]` (або поверни `url = "http://localhost:5050/v1/audio/speech"`, `model = "tts-1"`, `voice = "uk-UA-PolinaNeural"`).
