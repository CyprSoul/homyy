# Конектори (MCP) і Вікіпедія офлайн

## 1. MCP-конектори — «плагіни» для Хомі

**MCP** (Model Context Protocol) — відкритий стандарт: кожен конектор — маленька програма, яка дає ШІ
нові інструменти. Хомі підключає їх на старті (`agent\mcp_hub.py`), і Gemma користується ними так само,
як вбудованими (у журналі: `MCP «назва» підключено: …`).

### Що потрібно один раз
- **Node.js** (для конекторів через `npx`): https://nodejs.org → LTS → встановити.
- **uv** (для конекторів через `uvx`): у PowerShell `winget install astral-sh.uv`.
- Бібліотека: `.\.venv\Scripts\pip install -r agent\requirements.txt` (пакет `mcp`).

### Як додати конектор
У `agent\config.toml` — окремий розділ на кожен:
```toml
[mcp.servers.назва]
command = "npx"                       # або "uvx", або шлях до програми
args = ["-y", "пакет-конектора", "аргументи…"]
allow = ["інструмент1", "інструмент2"]  # необов'язково: лише ці інструменти
# env = { TOKEN = "…" }               # якщо конектору потрібен ключ — лише тут, не в чат
```
Перезапусти Хомі. **Порада:** підключай по одному й став `allow` — що менше інструментів бачить Gemma,
то точніше вона обирає (Gemma 26b плутається, коли інструментів десятки).

### Перевірені офіційні конектори для початку
| Що дає | Розділ для config.toml |
|---|---|
| **Файли** в обраній папці: читати, шукати, перелічувати | `command = "npx"`, `args = ["-y", "@modelcontextprotocol/server-filesystem", "C:\\Users\\igork\\Documents"]`, `allow = ["read_text_file", "list_directory", "search_files"]` |
| **Браузер** (Microsoft Playwright): відкрити сайт, натискати, заповнювати | `command = "npx"`, `args = ["-y", "@playwright/mcp@latest"]` |
| **Прочитати сторінку** за адресою | `command = "uvx"`, `args = ["mcp-server-fetch"]` |
| **Пам'ять-граф** (зв'язки між фактами) | `command = "npx"`, `args = ["-y", "@modelcontextprotocol/server-memory"]` |

Інші — каталоги: https://github.com/modelcontextprotocol/servers і https://mcp.so .
Перед підключенням стороннього конектора перевір, хто автор і що він робить: конектор отримує доступ до того,
що йому дозволиш (файли, акаунти). Ключі — лише в `config.toml`.

**Поки що Хомі підключає конектори, що працюють як програма (stdio).** Конектори «за адресою» (HTTP/SSE —
наприклад, вбудований MCP-сервер Home Assistant) — наступний крок, коли знадобиться.

## 2. Українська Вікіпедія офлайн (Kiwix)

Уся українська Вікіпедія (без картинок, ~5–7 ГБ) на твоєму ПК. Хомі шукає там енциклопедичні факти —
швидко, без інтернету й без вигадок (інструмент `wiki`). Для свіжого (новини, ціни, погода) лишається інтернет-пошук.

**Встановлення** (Docker Desktop має бути запущений):
```
cd C:\homyy\repo
.\scripts\install-kiwix.ps1
```
Скрипт сам знайде найсвіжішу версію, скачає (можна перервати — докачає), запустить сервер
`http://127.0.0.1:8090`. Потім у `agent\config.toml`:
```toml
[kiwix]
url = "http://127.0.0.1:8090"
```
і перезапусти Хомі. Перевір: «Хомі, хто такий Сковорода?» — у журналі `інструмент wiki …`.
Оновити Вікіпедію (раз на кілька місяців) — запустити скрипт ще раз.

**Автооновлення:** один раз запусти
`powershell -ExecutionPolicy Bypass -File .\scripts\schedule-kiwix-update.ps1` — щонеділі о 12:00
Windows сама перевірить, чи вийшла новіша Вікіпедія, і підмінить (журнал `C:\homyy\kiwix\update.log`).
Docker Desktop має бути запущений (увімкни в ньому «Start Docker Desktop when you sign in»).
