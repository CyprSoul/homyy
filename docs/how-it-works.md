# Як влаштована Хомі — довідник для подальшої роботи

Один файл, з якого можна зрозуміти все: **що** працює, **де** лежить, **як** запускається, **що робити**, коли щось зламалось.
Стан на 7 жовтня 2026. Якщо щось змінюється — оновлюй цей файл разом із кодом.

---

## 1. Загальна картина

Хомі — особиста голосова помічниця, що працює **повністю на ПК** (Windows 11, RTX 5080 16 ГБ, Core Ultra 9 285K, 32 ГБ ОЗП). Хмарних моделей немає й не буде.

```
мікрофон ─► VAD (webrtcvad) ─► детектор «Хооміі» (твій голос) ─► «Так?» або одразу питання
   │
   ▼
розпізнавання: NVIDIA Parakeet v3 (процесор, ~0.1 с) ── не українською? ─► Canary (примусово uk)
   │
   ▼
рефлекси без Gemma (музика, вікна, «натисни…», папки, «так/ні», «повтори», навички, уроки)
   │ якщо не рефлекс
   ▼
Gemma 4 26b через Ollama (характер + «як говорять люди» + уроки + пам'ять + інструменти)
   │  пише ПОТОКОМ — поки перше речення не готове, Хомі далі слухає
   ▼
голос Марічки (StyleTTS2) — перше речення звучить, поки Gemma дописує решту; можна перебити
   │
   ▼
сфера з точок на екрані (thinking-orbs) показує стан
```

Від кінця твоєї фрази до голосу ≈ **2–3 с** (розпізнавання 0.1 + Gemma 0.5–2 + перше речення голосу ~1.2).

## 6. Розмова — як саме вона слухає

1. **Виклик.** Звичайне «Хомі» → детектор твого голосу (схожість ≥ `sure_score` → одразу; нижче — ще перевірка текстом) → тихий сигнал (`ack = "beep"`, без «Так?») і одразу слухає — можна говорити далі без паузи. «Хомі, яка погода?» одним подихом — питання береться з тієї ж фрази (`one_breath`).
   **Старт:** коли Gemma завантажилась повністю, Хомі вітається своїми словами (Gemma, щоразу інакше; останні привітання — `agent\greetings.json`, щоб не повторювалась).
2. **Кінець фрази — Smart Turn v3.2** (`agent\turn\`, Pipecat, BSD-2, українська підтримується). Після 300 мс тиші модель за інтонацією вирішує «договорив чи ні»; ні — слухає далі (до 2.5 с тиші). Журнал: `⏸ договорив? 0.83 (після 300 мс тиші)`. Без моделі — старий спосіб: тиша + правила незакінченої фрази.
3. **Потік.** Gemma пише відповідь шматочками; кожне готове речення одразу йде в голос. Речення-обіцянки («зараз гляну»), «зробила» без дії чи не українською притримуються до перевірки всієї відповіді.
   **Поки перше речення не готове — слухає далі.** Заговорив знову → генерацію скасовано, думка склеюється, Gemma питається заново.
4. **Поки говорить — слухає теж.** «стоп / почекай / Хомі» → замовкає; «стоп, а яка погода?» → одразу нове питання; просто заговорив поверх (гучно, ≥0.6 с, не її слова) → замовкає й дослуховує. Тиху луну й шум ігнорує.
5. **Продовження** без нового «Хомі» — `follow_up_seconds` після відповіді. Коротке «так»/«ні» одразу після її питання не губиться (сигнал не стирає мікрофон; коротке слово під кінець її мови береться як відповідь; короткі фрази розпізнаються з тишею довкола).

## 7. Як Хомі тримає себе в руках (захисти від «тупості»)

| Проблема моделі | Захист у коді |
|---|---|
| Каже «поставила/відкрила», нічого не зробивши | `claims_action` → змушує викликати інструмент |
| «Зараз загляну», «хочеш, я пошукаю?» — і тиша | `promises_more` → зроби зараз або чесно скажи, що не вмієш |
| Перескакує на російську/англійську | перевірка мови → «перекажи українською» (крім прохань про переклад) |
| Русизми й суржик | словник `agent\data\russisms.tsv` |
| Чоловічий рід «радий» | `fix_gender` |
| «Ігоре» замість «Ігорю» | `name_vocative` у `[user]` |
| Додає годину до кожної відповіді | `strip_unasked_time` |
| Лекції на три абзаци | правила голосу + `voice_max_tokens` (160), без обірваних речень |
| Небезпечні дії | лише після твого «так», перевіряє **код** (`_needs_yes`), не модель |
| Складне питання | скажи «**подумай**» — вмикається режим міркування (10–30 с, розумніше) |

**Рефлекси без Gemma** (миттєві й надійні): музика (`media_intent`), «натисни на …», вікна, «що в папці / відкрий папку», виділений текст, «так/ні» на перепитування, вивчені навички.

## 7в. Як це перевіряється

`tests\test_scenarios.py` — «людина» говорить із Хомі за сценаріями (без мікрофона й без Gemma): потік, повтор, продовження думки, «стоп, а …» посеред мови, уроки, русизми, порожні обіцянки, «так» на перепитування, рефлекси. Запуск: `.\.venv\Scripts\python -m pytest -q tests`. Наживо — `docs\manual-tests.md`.

## 8. Чому саме так (рішення, які вже перевірені — не повторювати!)

| Рішення | Чому |
|---|---|
| Gemma 4 **26b** (не 12b, не хмара) | найкраща українська, що влазить у 16 ГБ; хмара — свідомо ні |
| Розпізнавання **на процесорі** | Whisper на відеокарті витісняв Gemma → відповідь 80+ с замість 1 с (заміряно) |
| **Parakeet**, а не Whisper | Whisper доповнює кожну фразу до 30 с → 3.2 с на процесорі; Parakeet — 0.1 с і найточніший на твоєму голосі (заміряно `stt_compare`) |
| Canary лише запасний | примусово українська, але вигадує слова на шумі («Дякую», «шматочки лайн») |
| `num_thread = 8` для Ollama | з усіма 24 ядрами швидкі чекали повільних: промпт 57 с → 0.5 с |
| `num_ctx = 16384` | голосу вистачає з запасом |
| `127.0.0.1`, а не `localhost` | Windows спершу пробує IPv6 і чекає ~2 с на кожен запит |
| Голос відкривається лише на час мови | постійно відкритий звук шипить у навушниках |
| Швидкість сфери не змінюється на ходу | бібліотека множить увесь час від старту на швидкість → «шалене» кружляння |
| Сфера — окремий процес | анімація не гальмує розмову; сама закривається, коли Хомі немає |

## 10. Коли щось не так

| Симптом | Що робити |
|---|---|
| Хомі не стартує з ярлика | закрити зависші копії: `Get-Process pythonw, python \| Stop-Process -Force`, потім `restart-homyy.ps1` |
| Довго думає (десятки секунд) | `ollama ps` — Gemma має бути ~74% GPU; закрити ігри/важкі програми; не ставити розпізнавання на `cuda` |
| Каже Поліною замість Марічки | Docker Desktop запущений? `docker ps` — `tts_uk_api` і `tts_uk_gradio` мають бути `Up (healthy)` |
| «Чує» те, чого ти не казав | рядки `👂` у журналі; перенавчити детектор `record_wake --more` |
| Перебиває / не дослуховує | `command_silence_ms` більше (1000–1200) |
| Не реагує, коли перебиваєш | у журналі нема `✋` — підкрутити фільтр гучності (`loud_enough`, factor) |
| Обрізає перші склади на колонці | `[audio] keep_output_open = true`, `keepalive_db = -70` |
| Скрипти `.ps1` не запускаються | один раз: `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` |
| Стара сфера на екрані | вона сирота — `restart-homyy.ps1` закриває й її |
| Перевірити все без розмов | `python -m agent.bench` |

## Щоденник розмов (agent/diary.py)
Після кожної розмови (від 2 реплік) Gemma у фоні одним коротким запитом пише підсумок на 1–3 речення
в `agent\diary.jsonl` (у журналі: `📔 щоденник: …`). Останні 3 підсумки завжди є в її підказці
(«ОСТАННІ НАШІ РОЗМОВИ»), старіші вона знаходить інструментом `recall`. Вимкнути: `[diary] enabled = false`.
Очистити пам'ять розмов: видалити `agent\diary.jsonl`.

## Хомі пише сторінки (agent/builder.py)
«Хомі, зроби мені сторінку для тренувань з графіком прогресу» → інструмент `make_page`: Gemma у фоні пише
один HTML-файл (1–2 хв; поки пише, відповідає повільніше — це той самий мозок), кладе в
`Документи\Хомі\сторінки`, відкриває в браузері й каже «готово» (як нагадування, подвійний сигнал).
Дані сторінка зберігає в браузері (localStorage). Правки — `edit_page` («зроби кнопки більшими»;
попередня версія лишається поруч як `.bak.html`), відкрити знову — `open_page` («відкрий сторінку тренувань»).
Прогрес видно під сферою жовтим рядком «🛠 пишу 1:05 · 142 р.», у журналі (`🛠`) і на питання «як там сайт?» (`page_status`).

**Режим «якісно»** (`[pages] review_rounds = 2`): після написання Gemma двічі перечитує свій код, шукає помилки
й виправляє (5–10 хв замість 2). Якщо встановлений Node.js — він ще й перевіряє синтаксис JavaScript, і
знайдені помилки йдуть Gemma на виправлення. «Напиши швидко/чернетку» — без перевірки.

**Програміст Gemini** (`[coder] gemini_key`): якщо вказано ключ, код сторінок пише Google Gemini через офіційний
API (безкоштовний ліміт), а Хомі лише передає завдання, зберігає файл, відкриває й каже «готово». У Google іде
тільки завдання на код. Немає інтернету, вичерпано ліміт чи немає ключа — пише сама Gemma, як раніше.
Ключ: https://aistudio.google.com/apikey . Модель — `model` (за замовчуванням `gemini-flash-latest`, найновіша Flash).
