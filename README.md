# Хомі (Homyy)

Особиста голосова помічниця, яка живе на домашньому ПК і працює локально, без хмари.

Вона розмовляє голосом, шукає інформацію, пам'ятає господаря, бачить картинки й екран, малює, допомагає з мовами, тренуваннями, саморозвитком і керує Windows.

**Активація:** протяжне «Хоооуммміііі». Звичайне коротке «Хомі» в розмові її не будить.

## Залізо

| Компонент | Модель |
|---|---|
| Процесор | Intel Core Ultra 9 285K |
| ОЗП | 32 ГБ |
| Відеокарта | NVIDIA GeForce RTX 5080 (16 ГБ) |
| Диск | 2.27 ТБ |

## План

Етапи йдуть по порядку: кожен наступний спирається на попередній. Етапи 0–7 не потребують програмування, лише встановлення й налаштування. Етапи 8–9 ми пишемо разом.

### Етап 0. Підготовка
- [x] Оновити драйвер NVIDIA (GeForce Experience / NVIDIA App)
- [x] Увімкнути WSL2 і встановити **Docker Desktop** (у ньому житимуть Open WebUI та пошук)
- [x] Встановити **Python 3.11**
- [x] Встановити **Git**

### Етап 1. Мозок 🧠
- [ ] Встановити **Ollama**
- [ ] Завантажити основну модель: `qwen3:14b`
- [ ] Завантажити модель із зором: `gemma3:12b`
- [ ] Перевірити: поспілкуватися з моделлю в терміналі

### Етап 2. Обличчя: Open WebUI
- [ ] Запустити **Open WebUI** у Docker і підключити до Ollama
- [ ] Створити персонажа **«Хомі»**: дівчина, свій характер, говорить українською (системний промпт)
- [ ] Увімкнути **пам'ять** → пункт 3
- [ ] Завантажити перші документи в **базу знань** → пункт 5
- [ ] Перевірити **розпізнавання картинок** через `gemma3:12b` → пункт 6
- [ ] Увімкнути **виконання коду** → пункт 10

### Етап 3. Голос 🎙️
- [ ] Розпізнавання мови: **Whisper** (large-v3 / turbo) → пункт 1
- [ ] Синтез мови: жіночий український голос (**Piper**, голоси `uk_UA`)
- [ ] Перевірити голосовий режим (дзвінок) в Open WebUI

### Етап 4. Інтернет 🔎
- [ ] Запустити **SearXNG** у Docker і підключити як веб-пошук → пункт 2
- [ ] Перевірити конспект YouTube за посиланням → пункт 9

### Етап 5. Телефон 📱
- [ ] Відкрити Open WebUI з телефона вдома по Wi-Fi
- [ ] Встановити **Tailscale** на ПК і телефон, щоб Хомі була доступна поза домом → пункт 7
- [ ] Додати Open WebUI на головний екран телефона як застосунок

### Етап 6. Художниця 🎨
- [ ] Встановити **ComfyUI**
- [ ] Завантажити моделі **Flux** / **SDXL**
- [ ] Підключити генерацію картинок до Open WebUI → пункт 8

### Етап 7. Пошта й календар 📅
- [ ] Підключити Gmail / Google Calendar (або Outlook) через інструменти Open WebUI → пункт 11

### Етап 8. Справжня Хомі: власний застосунок 🖥️ (програмуємо разом)
Окрема програма на Python, яка працює у фоні Windows:
- [ ] Слово-активатор: навчити **openWakeWord** на записах протяжного «Хоооуммміііі» → пункт 12
- [ ] Голосовий цикл: мікрофон → Whisper → Ollama → голос
- [ ] Керування Windows: відкрити програму, вимкнути ПК за таймером, навести лад у файлах (з підтвердженням) → пункт 13
- [ ] Музика й медіа: пауза, гучність, увімкнути плейлист → пункт 14
- [ ] Екран: «що в мене на екрані?» → пункт 4
- [ ] Браузер: відкрити сайт і знайти потрібне → пункт 4
- [ ] Спільна пам'ять з Open WebUI

### Етап 9. Свій голос 🔊
- [ ] Обрати або навчити унікальний жіночий голос для Хомі → пункт 15

## Важливо
- Хомі працює, лише коли ПК увімкнений.
- Перед небезпечними діями (видалення, зміна налаштувань) Хомі завжди питає підтвердження.
- Українською вона говорить трохи гірше, ніж англійською, але для щоденного спілкування цього достатньо.
